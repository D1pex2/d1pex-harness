# MODEL-23. Переменная названа именем общего модуля или глобального свойства

## Идентификатор и группа

Идентификатор: `MODEL-23`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Локальная переменная, переменная цикла или параметр процедуры названы именем общего модуля (Пользователи, ОбщегоНазначения) или свойства глобального контекста (Метаданные, Справочники, Документы, Константы, ПараметрыСеанса и др.)

## Почему дефект

Локальное имя перекрывает общий модуль или глобальное свойство в области процедуры. Дальше в той же процедуре вызов Пользователи.ТекущийПользователь() или обращение Справочники.Контрагенты идёт к локальной переменной, а не к модулю; модуль может не компилироваться или молча работать с другим объектом. Ошибка не видна при чтении, пока имя не совпало с нужным вызовом.

## Законная форма

Имя локальной переменной - существительное по содержанию данных с поясняющим словом: СоответствиеПользователей, ТаблицаПользователей, ПользователиДляОтбора. Обращение к самому модулю или свойству (Пользователи.ТекущийПользователь(), Справочники.Контрагенты.НайтиПоКоду(...)) находкой не является.

```bsl
СоответствиеПользователей = Новый Соответствие;
Для Каждого СтрокаПользователя Из ТаблицаПользователей Цикл
    СоответствиеПользователей.Вставить(СтрокаПользователя.Код, СтрокаПользователя.Ссылка);
КонецЦикла;
```

## Как чинить

Переименуй переменную или параметр по содержанию данных (СоответствиеПользователей, СписокДокументов), поправь обращения в процедуре. Список имён правила неполон: имена общих модулей конкретной конфигурации сверяй с каталогом CommonModules.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | bsl_validate:MODEL-23 | static |

Обоснование чтения: lint знает фиксированный список имён (глобальный контекст и частые модули БСП); имена общих модулей прикладной конфигурации и перекрытие через другие конструкции требуют чтения.

Ограничения детектора bsl_validate:MODEL-23: ловит присваивание в начале строки, переменную цикла Для Каждого ... Из и параметр в заголовке Процедура/Функция. Присваивание после Тогда/Иначе в одной строке и объявление через Перем не находятся. Комментарии и строковые литералы отбрасываются.
